# 🤖 Rule-Based Chatbot Using Python

## 📌 Project Description

The Rule-Based Chatbot is a simple conversational program developed using Python. It interacts with users and provides responses based on predefined rules and keywords.

The chatbot can answer basic questions, greet users, provide study tips, display the current date and time, and tell jokes. It is a beginner-friendly project that demonstrates basic chatbot development using Python.

## ✨ Features

- 👋 Responds to greetings such as Hi, Hello, and Hey.
- 🤖 Introduces itself when asked about its name.
- 🐍 Provides basic information about Python.
- 🧠 Explains Artificial Intelligence and Machine Learning.
- 🎓 Gives simple study tips for exams.
- 🕒 Displays the current time.
- 📅 Displays today's date.
- 😂 Tells random programming jokes.
- 💬 Responds to thank-you messages.
- ❓ Provides a help menu with supported questions.
- 👋 Ends the conversation when the user types Bye, Exit, or Quit.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Environment:** Jupyter Notebook
- **Libraries:** `datetime` and `random`

## ⚙️ How It Works

1. The user enters a message.
2. The chatbot converts the input to lowercase and removes extra spaces.
3. It checks the message against predefined rules and keywords.
4. It generates an appropriate response.
5. The conversation continues until the user enters a goodbye command.

## 📋 Requirements

- Python 3.x
- Jupyter Notebook or JupyterLab

The `datetime` and `random` libraries are included with Python, so no additional package installation is required.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open Jupyter Notebook.
3. Open `Rule_Based_Chatbot.ipynb`.
4. Run the notebook cells in order.
5. Enter a message when prompted.
6. Type `help` to see the available questions.
7. Type `bye` to end the conversation.
